## 4. The Generated-Stale README Problem (dedicated)

**Scope.** The marker `<!-- GENERATED BY scripts/generate-repository-intelligence.mjs ON 2026-06-08T16:24:47.587Z … -->` appears in **120 `.md`**. Of these, **15 merely *quote* the marker** (marker not on line 1 — the four audit folders citing it as a finding, plus root `AGENTS.md` and `LETBUYY_AGENTS_V2.md` whose preambles reference the retired generator at L7). The **truly generated** population (marker on **line 1**) is **105**, of which **97 are live** (8 are under `docs/archive`):

| Class | Count | Notable |
|---|---:|---|
| Single-domain `docs/<domain>/README.md` | **65** | `database`, `payments`, `checkout`, `auth`, `security`, `webhooks`, `events`, `billing`, `state-management`, … |
| App `AGENTS.md` | **12** | all canonical + frozen + reserved app roots |
| Package `AGENTS.md` | **18** | the older `*-core` / dart / typescript packages |
| `docs/architecture/README.md` + `master-system-intelligence.md` | **2** | the master is **192,565 lines** |

**Why this is the hardest call.** The generator is **hard-retired** (`scripts/generate-repository-intelligence.mjs` is 15 lines: `const RETIRED… = true; … process.exit(1)`), per `PHASE-A-HARD-002`. The retirement note explicitly forbids re-running it ("Repository scans may not regenerate governance authority or promote current tree drift into canonical law"). So **regeneration is off the table** — every generated doc is frozen at the 2026-06-08 tree and cannot be refreshed by tooling.

**Concrete staleness (verified):**
- **45 of the live generated READMEs reference the now-deleted `FORENSIC_REPORT/` paths** (830 occurrences). Those directories are deleted from the live tree and archived under `docs/archive/root-governance-2026-06-10/directories/FORENSIC_REPORT` (43 `.md`, untracked) — so every such reference is a **dangling pointer**. E.g. `docs/database/README.md:18` → `FORENSIC_REPORT/03-application-reports.md`; `:20` → `FORENSIC_REPORT_OPERATIONS/15-evidence-appendix.md`.
- Frozen migration/file snapshots: `docs/database/README.md` lists migrations through `083_*` + "288 more"; untracked migrations **162–166** exist on disk and are invisible to it.
- Package inventories frozen: `packages/auth-core/AGENTS.md:10` "Files scanned: 6".
- Domain-string drift is **narrow**: only **2** READMEs still assert literal `letbuyy.store` (`README.md`, `docs/auth/2026-06-08-identity-platform-transformation/README.md`) — canonical is `letbuyy.com`. (The "letbuyy.store" framing from prior audits over-counts; the real generated-README rot is the FORENSIC/migration dangling refs.)

**Recommendation (per doc-class):**

1. **`master-system-intelligence.md` (192,565 lines) → DELETE.** Un-maintainable by hand, un-regenerable by tool, and every domain README that "defers to the exhaustive catalog" points at it. Replace the pointer, not the file. Keep one archived snapshot under `docs/archive/architecture/` (a `SYSTEM_INTELLIGENCE_REPORT.md` already exists there) and delete the live copy.
2. **65 `docs/<domain>/README.md` → REWRITE-by-hand to thin stubs, or DELETE the empty ones.** The valuable, durable content is the **Governance Rules** + **AI Execution Notes** boilerplate (identical across files); the volatile **Source-Derived Files / Immediate Risks** tables are the stale part. Recommended: strip the generated header + the file/risk tables, keep a 5–10 line hand stub per domain that points to the owning runtime and canon. Domains that are pure scan noise (no real ownership) → DELETE.
3. **12 app + 18 package `AGENTS.md` → REWRITE.** Keep the **Ownership Rules**; delete the **Inventory/Manifest/scan snapshot**; drop the generated header. **DELETE outright the 5 generated app AGENTS.md for frozen/reserved roots** (`app-marketplace`, `developer-portal`, `theme-marketplace`, `mobile/operator-app`, `mobile/shopper-app`) — CLAUDE.md forbids treating them as active topology, so a per-root AGENTS.md asserting active boundaries is actively wrong.
4. **`docs/architecture/README.md` → REWRITE** to a 1-paragraph index pointing at the canon + the (archived) intelligence snapshot.
5. **`docs/README.md` and `docs/agents/repository-map.md` → REWRITE** (both generated) to hand-authored indices.

Net: of the 97, **~2 DELETE outright** (master + maybe architecture/README), **~5 DELETE** (frozen-root app AGENTS), **~90 REWRITE-to-stub** (with an option to DELETE the empty domain READMEs after inspection).
