# Inter Variable

`inter-variable.woff2` is Inter Variable 4.66, sourced from the [Inter project](https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2). It is used by the Merchant web app as a locally hosted, licensed approximation of the [Shopify admin's ShopifyInter face](https://shopify.dev/docs/apps/build/app-home/polaris2). The accompanying SIL Open Font License is in `INTER-OFL-LICENSE.txt`.
