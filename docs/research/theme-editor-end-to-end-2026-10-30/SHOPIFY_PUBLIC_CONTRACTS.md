# Shopify public editor contracts

Accessed 30 October 2026. These are **OFFICIAL SHOPIFY DOCUMENTATION**, not observations of the user's account or knowledge of Shopify private internals. See [UI workflows](SHOPIFY_UI_WORKFLOWS.md) for the inaccessible live inspection.

| Contract | Publicly documented behavior | LetBuyy interpretation |
| --- | --- | --- |
| Workspace | [Features overview](https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/features-overview): menu bar has theme, market and template menus, sidebar modes, preview, inspector, mobile mode, undo/redo and keyboard shortcuts. | Use the interaction as a usability benchmark; do not import Shopify's market or app-embed architecture without a LetBuyy owner decision. |
| Section groups | [Customizing sections](https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/customizing-sections): Header, Template and Footer groups; header/footer shared across page templates. Rows can be expanded, moved where allowed, hidden and removed. | Section group is a first-class part of insertion/reorder/persistence. Never imply a section is shared merely because it looks like a header. |
| Limits and sources | [Sections and blocks](https://help.shopify.com/en/manual/online-store/themes/theme-structure/sections-and-blocks): up to 25 sections and 1,250 blocks per template; nested blocks up to eight levels; actual type/section caps vary by theme/version. | LetBuyy uses its own declared limits. The catalog must be derived from the installed package and current parent/template. |
| Preview inspector | [Preview inspector](https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/preview-inspector): click an outlined element for settings; plus at selected section top/bottom inserts above/below; hovering a block offers allowed block choices. Mobile selection uses a sheet, with documented customer-navigation gesture. | Exact before/after and section/block identity are acceptance requirements. UX gestures can differ if accessible and predictable. |
| Section schema | [Section schema](https://shopify.dev/docs/storefronts/themes/architecture/sections/section-schema): `settings`, `blocks`, `max_blocks`, `presets`, `limit`, `enabled_on`, `disabled_on` and defaults govern editor availability and initial state. | The equivalent LetBuyy installed schema must drive both UI and gateway validation. |
| Block schema | [Theme block schema](https://shopify.dev/docs/storefronts/themes/architecture/blocks/theme-blocks/schema): reusable theme blocks declare settings, child block allowances and presets; app block markers are a separate source. | First-party nested blocks only. LetBuyy third-party app blocks remain frozen under `NEVER-R3`. |
| Settings and dynamic sources | [Settings](https://shopify.dev/docs/storefronts/themes/architecture/settings) supports theme/section/block settings and conditional visibility. [Dynamic sources](https://shopify.dev/docs/storefronts/themes/architecture/settings/dynamic-sources) bind compatible resource attributes/metafields; their availability depends on resource context. | Explicit tenant-owned resource selection and typed field behavior; no arbitrary Liquid expression from merchant input. Global settings and contextual sources have different scope. |
| Templates | [Templates](https://shopify.dev/docs/storefronts/themes/architecture/templates) distinguishes page types and JSON template structure. Alternate templates are separate from the resource assignment that chooses one. | Store template key, preview resource and resource assignment as distinct concepts. LetBuyy `page`, `blog`, and `article` must not collapse. |
| CSS | [Adding custom CSS](https://help.shopify.com/en/manual/online-store/themes/customizing-themes/edit-code/add-css): global and section CSS have different scope; Checkout excluded; documented length and syntax restrictions. | LetBuyy can offer sanitized, scoped CSS only after editor→gateway→render proof. Shopify's exact quotas and URL policy do not become LetBuyy defaults automatically. |
| Publication | [Publishing themes](https://help.shopify.com/en/manual/online-store/themes/managing-themes/publishing-themes): one published theme at a time; draft themes remain available; publication can be initiated from admin/editor. | Keep draft save distinct from an explicit immutable release. Shopify conflict behavior was not exercised here. |
| Custom Liquid | [Customizing sections](https://help.shopify.com/en/manual/online-store/themes/customizing-themes/theme-editor/customizing-sections) identifies Custom Liquid as an eligible section in some groups/themes. | Literal merchant-executable Liquid conflicts with LetBuyy `THEME-R4`; recommend bounded data-only rich content or a constrained non-executable grammar. An ARB constitutional amendment is needed for literal executable parity. |

Do not infer Horizon's current 19 global groups, current catalog thumbnails, control defaults, Canvas behavior in this account, or the user's theme version from these general pages. Shopify's UI and plan-specific availability can change independently of the public schema contract.
