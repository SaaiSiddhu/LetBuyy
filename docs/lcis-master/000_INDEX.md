1. **Accretion, not architecture** — 12+ generations, 2 runtimes, 202 engine files / 388 artifacts, 117 self-issued certs, **zero deployed presence**. The intelligence system is its own discovery problem.

3. **One engine, two faces** — agent/CLI/MCP API (backend) + `apps/lcis` (human app, **RESERVED until earned**: named runtime, SSO, ≥1 live adapter, validator coverage; **security-sensitive**).
4. **MVP is NOT the app** — blast-radius / change-safety via **CLI + GitHub PR-check + MCP tool** (meet engineers where they are); the 8-surface app is the 1-year destination.
5. **Defer CIP** (product-agnostic) — "Papaa" doesn't exist; LetBuyy-first; moat = **India-first commerce depth** (COD before GST), realized by **earning live data** (Supabase first), not a 13th layer.
6. **Deterministic retrieval, not "no RAG"** — structural graph + zero-dep **BM25 prose index** + **decisions-as-JSON** (answers "why"); never embedding-RAG.
7. **Anti-accretion governance** — no new version names; subtraction by default; adversarial review replaces self-certification; decisions + gaps become queryable nodes; validator gate stays supreme.
