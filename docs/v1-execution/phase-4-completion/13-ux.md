# 13 — UX Consistency

**Readiness: ~82%.** Strong, consistent foundation across the sampled admin pages.

## Real (9 pages sampled: dashboard, products, orders, customers, reviews, billing, inventory, coupons, users)
Nearly all have: skeleton loading, EmptyState, error handling, responsive layout, `@letbuyy/ui` composition + `--lb-*` tokens, INR + en-IN formatting, ConfirmDialog/StepUpDialog on destructive actions, aria coverage (inventory has the best: `aria-invalid`/`aria-label`; dashboard `aria-live`).

## Systemic gaps (documented)
- **Coupons uses a raw `<table>`** (only page not on `@letbuyy/ui <Table>`) → mobile (~360px) gets horizontal scroll, not the card adaptation. Functional regression. P1 (UI).
- **Orders + Customers** surface the initial load error only inside EmptyState, not a top-level `Banner variant="critical"` like the other 7 pages. Inconsistent. P2.
- Raw pixel values: `inventory:234` (`min-w-[112px]`), `products/new:1132–1167` (4× `w-[...]`) → should use `--lb-size-*`. P2.
