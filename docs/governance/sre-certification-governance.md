# SRE Certification Governance

SRE certification is owned by SLO definitions, error-budget snapshots, incident readiness, and recovery timing evidence.

Rules:

- Certification must evaluate SLO, SLA, error budget, runtime health, deployment readiness, operational maturity, runtime reliability, recovery timing, and incident readiness.
- Execute mode records SRE evidence through runtime projections.
- Error-budget freeze or exhausted status blocks production promotion unless an explicit governed override exists.
- Incident and failover drill evidence must feed SRE scoring.
- SRE scores must be traceable to runtime data, not static claims.
