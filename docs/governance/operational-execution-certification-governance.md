# Operational Execution Certification Governance

This phase adds executable local certification evidence for distributed recovery behavior. It does not claim live production certification, provider failover success, production SLO compliance, or Cloudflare deployment success.

## Authority

- Evidence contract: `config/runtime/operational-certification-evidence.json`
- Recovery SLO contract: `config/runtime/recovery-slo-contract.json`
- Local harness: `infrastructure/scripts/operations/run-operational-certification.mjs`
- Generated evidence directory: `artifacts/operational-certification/`
- Validator chain: `pnpm run validate:operational-certification`

## Evidence Rules

- Local evidence must be generated by executing the harness.
- Local evidence must carry `certification: false` and `production_certification: false`.
- Local timing is observed timing from the current machine, not production SLO evidence.
- Evidence artifacts are ignored and must not become source authority.
- Live production certification still requires provider credentials, approval, telemetry endpoints, and operations evidence recording.

## Required Certification Categories

- Replay recovery certification.
- Rollback execution certification.
- Queue rebuild certification.
- WAL restoration certification.
- Lease failover certification.
- Durable Object recovery certification.
- Orchestration recovery certification.

## Telemetry Lineage

Every evidence item must carry:

- `trace_id`
- `span_id`
- `parent_span_id`
- `duration_ms`
- `input_checksum`
- `result_checksum`
- `causality_checksum`

The lineage is intended to make local evidence reconstructable and tamper-detectable. It is not a replacement for live OpenTelemetry or provider telemetry.

## Fail-Closed Behavior

Validators hard fail when:

- Recovery SLO budgets are missing.
- Evidence categories are missing.
- Harness safety markers are missing.
- Telemetry lineage is incomplete.
- Durable Object evidence does not distinguish local model execution from live provider recovery.
- Evidence artifact directories are not ignored.

## Execution

Run local evidence generation with:

```bash
pnpm run certify:operational:local
```

This writes ignored evidence under `artifacts/operational-certification/`. The final report may summarize the result, but checked-in source must not claim live operational success from local evidence.
