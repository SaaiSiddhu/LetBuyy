## Critical Pre-Evaluation Finding: Three Committed Exports Point to Untracked Source Files

Before row-level analysis, a build-integrity hazard must be disclosed.

`packages/theme-engine/src/index.ts` at HEAD (`7e1441a6`) contains three export lines that have been present since at least the Phase M baseline commit (`9186188e`):

```
export * from './industry-experience-map';
export * from './theme-bundle-core';
export * from './experience-fonts';
```

Command: `git show HEAD:packages/theme-engine/src/index.ts | grep "industry-experience\|theme-bundle-core\|experience-fonts"`

Result: all three lines are present in every commit back to the Phase M anchor.

Command: `git ls-files packages/theme-engine/src/experience-fonts.ts packages/theme-engine/src/industry-experience-map.ts packages/theme-engine/src/theme-bundle-core.ts`

Result: no output. None of the three files is tracked by git.

The files exist on disk as untracked FOREIGN_WIP:
```
?? packages/theme-engine/src/experience-fonts.ts
?? packages/theme-engine/src/industry-experience-map.ts
?? packages/theme-engine/src/theme-bundle-core.ts
```
(from: `git status --porcelain | grep "theme-engine"`)

**Consequence:** a fresh clone of the committed repository would fail to build the `@letbuyy/theme-engine` package because `index.ts` re-exports three modules that do not exist in git. The Phase-M matrix treated these modules as committed source (`packages/theme-engine/src/experience-fonts.ts` at row 58, `src/industry-experience-map.ts` at row 9, `src/theme-bundle-core.ts` at rows 9 and 64). They exist in the working tree only. Status for every capability that depends on them is **FOREIGN_WIP** against the git-committed state.

This does not block AF.0 discovery; it is carried to the AF_12 STOP/GO decision as a CRITICAL build-integrity gap.
