## What is live today, re-verified against current source (not carried forward from SUSTAINED-I's
## 2026-09-24 finding without checking)

- **`employees`** decides every real staff-permission request. `middleware/staff-permission.ts`'s
  `resolveGrants` queries `employees` (`store_id`, `user_id`, `status = 'active'`, `deleted_at IS
  NULL`) **fresh on every request** — no token-embedded permission snapshot, so revocation
  (`status` leaving `'active'`) takes effect on the caller's very next request. This is a structural
  property, not something a test could regress unnoticed: there is no cache or claim that could go
  stale, because nothing is ever cached. 9/9 `staff-permission.test.ts` pass (owner bypass, wildcard
  and prefix grants, empty-grants denial, fail-closed on an unrecognised `rbac mode`).
- **`employees.status`** governs `'active'`/anything-else; `employees.store_id` is the site (never a
  client-supplied value — this route family reads it from the resolved tenant, matching I1).
- **Self-service staff invitation is already retired, not merely untested.** `POST /employees/invite`
  is a **hard-disabled stub** (`routes/employee.ts:317`, "Staff self-service invites are not
  available. Add staff directly instead." — Phase N3's own retirement, cited in the route's comment).
  There is no invite-token/email-accept flow to replay, because it does not exist. A merchant owner
  adds staff directly through `POST /employees`. This narrows the mandate's "invitation cannot be
  replayed" requirement to "there is no invitation mechanism to replay" — verified, not assumed.
- **Owner privileges cannot be self-assigned through this path**: `POST /employees`'s own gate (not
  fully re-read this phase line-by-line, but confirmed mounted behind the same permission system, and
  no route in `employee.ts` writes a caller's own `store_id`/`role` from a client-supplied value for
  themselves — every write target is a *different* `user_id` than the caller's own session).

  `fallbackPlan` parameters and returns them unchanged whenever no membership row is found — which,
