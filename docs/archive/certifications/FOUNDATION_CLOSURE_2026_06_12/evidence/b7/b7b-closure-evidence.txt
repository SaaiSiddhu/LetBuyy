--- AUTH_SECRET FALLBACK REMOVAL RATIONALE ---
PLATFORM_CONSOLE_SESSION_SECRET is provisioned independently (already in secret matrix).
AUTH_SECRET is a shared Next-app JWT secret — different security domain from console sessions.
Using it as a fallback allows AUTH_SECRET compromise to impersonate console sessions.
Removal enforced: production gate returns null when PLATFORM_CONSOLE_SESSION_SECRET is unsafe.
