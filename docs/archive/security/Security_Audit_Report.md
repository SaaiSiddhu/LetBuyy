## 2. Critical Vulnerabilities

### 2.1 Committed Production Secrets (CRITICAL)
**File:** `all.env` — 9 live production secrets committed to git:
- Supabase anon key and service role key
- Upstash Redis token
- Resend API key
- Razorpay key ID and secret
- AUTH_SECRET, CSRF_SECRET, CUSTOMER_SESSION_SECRET

**Impact:** Any person with repository access can impersonate the platform, access the database with admin privileges, send emails, and process payments.

**Remediation:** Rotate all secrets immediately, purge from git history, add to `.gitignore`.

### 2.2 Missing Webhook Signature Verification (CRITICAL)
**Endpoints affected:** Razorpay, Stripe, PayPal webhook handlers

**Impact:** Attacker can forge payment confirmation webhooks, causing orders to be confirmed without actual payment.

**Remediation:** Implement `stripe.webhooks.constructEvent()`, Razorpay HMAC-SHA256 verification, PayPal IPN verification.

### 2.3 Incomplete Rate Limiting (CRITICAL)
**Endpoints affected:** Many auth endpoints lack rate limiting

**Impact:** Brute force attacks on login, OTP verification, and password reset.

**Remediation:** Add Upstash Redis rate limiting: 5/min for OTP/password, 10/min for login, 3/min for reset.

### 2.4 Missing CSRF Protection (HIGH)
**Issue:** CSRF_SECRET exists in env vars but no middleware validates tokens.

**Impact:** Cross-site request forgery on all mutating endpoints.

**Remediation:** Implement double-submit cookie pattern middleware.

### 2.5 Client-Sent Prices Trusted (CRITICAL)
**Issue:** No server-side price recalculation before payment processing.

**Impact:** Customer could modify checkout payload to pay less than actual price.

**Remediation:** Always recalculate total from product prices in database before creating payment session.

### 2.6 Internal Error Details Exposed (HIGH)
**Issue:** API responses include raw Supabase error messages.

**Impact:** Information disclosure — attackers learn database structure.

**Remediation:** Sanitize all error responses, log internally, return generic codes.

### 2.7 Missing Security Headers (MEDIUM)
**Issue:** No security headers on any responses.

**Missing headers:** HSTS, X-Content-Type-Options, X-Frame-Options, X-XSS-Protection.

**Remediation:** Add security headers middleware to all apps.
