## 2. Critical Gaps (Block Launch)

1. 🔴 **Committed secrets** — Must rotate immediately
2. 🔴 **Webhook signature verification** — Payment security vulnerability
3. 🔴 **Rate limiting** — Auth brute force vulnerability
4. 🔴 **Complete payment integration** — Cannot process real transactions
5. 🔴 **Cart & checkout completion** — Core e-commerce flow broken

## 6. Detailed Remediation Plan

### Security Gaps (Prioritized)

| # | Gap | Fix | Effort | Dependency |
|---|-----|-----|--------|------------|
| 1 | Secrets in repo | Rotate ALL 9 keys, purge git history with BFG, update env vars in Vercel/Cloudflare | 3h | None (do first) |
| 2 | Webhook verification | Implement HMAC-SHA256 for Razorpay (`X-Razorpay-Signature`), Stripe (`Stripe-Signature`) | 3h | After #1 |
| 3 | Rate limiting | Add Upstash Redis rate limiter to all unprotected endpoints | 2h | None |
| 4 | Client prices | Server-side price recalculation: fetch product prices from DB, ignore client-sent amounts | 3h | Schema fixes |
| 5 | CSRF middleware | Implement double-submit cookie: generate token on GET, validate on POST/PUT/DELETE | 3h | None |
| 6 | Error sanitization | Catch all errors in middleware, log full trace to Axiom, return sanitized response | 3h | Axiom setup |
| 7 | Security headers | Add middleware in Hono + Next.js to set HSTS, CSP, X-Frame-Options, etc. | 2h | None |
