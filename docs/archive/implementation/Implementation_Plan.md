## Phase 1 — Schema & Security (40-50h)
- Schema compliance: soft deletes, audit columns, version columns, order_items table

- API consistency: versioning prefix, error format standardization, Zod validation

## Phase 2 — Complete P0 Features (120-150h)
- Auth system: refresh token rotation, 2FA, console access controls
- Admin dashboard: shipping, inventory, customers, blog, media library, coupons
- Storefront: cart persistence, checkout completion, search, customer accounts
- Payments: Razorpay, Stripe, PayPal full integration, subscriptions, refunds
- Console: dashboard, user/store management, audit logs, feature flags
- Team portal: tickets, moderation, RBAC

## Phase 3 — Polish, Testing & Launch (80-100h)
- Testing: Vitest for web, Flutter tests, unit/integration/e2e
- UI/UX: font standardization, design tokens, dark mode verification, skeletons
- Performance: KV caching, R2 storage, Redis caching, Lighthouse audits
- Monitoring: structured logging, error tracking, uptime monitoring
- Deployment: CI/CD pipeline, staging environment, domain DNS

## Phase 4 — P1 Features (50-60h)

- Theme marketplace developer submission
- App Store developer API
- Multi-language, email campaigns, abandoned cart recovery
- PDF resume export, bulk import/export, multi-currency

## Phase 5 — P2 Features (40-50h)

### Phase 3 — DONE when:

## Definition of Done (Global)

```
Every feature is DONE when:
  ✅ Code passes lint (ESLint/Biome) with zero warnings
  ✅ Unit tests written and passing
  ✅ API endpoint has Zod validation on input
  ✅ API endpoint has rate limiting
  ✅ Dark mode verified
  ✅ Mobile responsive (320px tested)
  ✅ Skeleton loading state (no spinners)
  ✅ Error state handled (toast + fallback UI)
  ✅ Accessibility: keyboard nav + ARIA labels
  ✅ No hardcoded colors (design tokens only)
  ✅ No console.log in production code
  ✅ PR reviewed and approved
```
