# YouTube — 12 Week Plan (1 long-form video/week)

**Publish:** Fridays. **Length:** 6–12 min (long enough to build trust, short enough to finish).
**Voice:** spoken delivery naturally Tanglish; titles/descriptions English + searchable.
**Per video:** Title (+ alt) · Description (with timestamps) · Thumbnail · Hook (first 15s) · Outline · CTA.
**Reuse rule:** every video → 1 IG reel cut + 1 X thread + 1 LinkedIn reflection. One shoot feeds four platforms.
**Playlists:** "Month 1 — The Why" · "Month 2 — The Build" · "Month 3 — The Climb."

> The weekly vlog is separate — see `FOUNDER_VLOG_PLAN.md`. This file is the *main* weekly video.

# Production notes (keep it sustainable)
- **Batch filming:** record talking-head segments for 2 videos in one sitting (Tue/Thu from the rhythm grid).
- **B-roll bank:** keep a folder of reusable clips — typing, chai, gym, walking to college, whiteboard — so editing is fast.
- **No-fake on screen:** any UI shown must be real or *clearly labeled* "concept/mock." Never imply traction you don't have.
- **Thumbnails:** all use brand violet `#8B5CF6`, Ink `#111827` text, one big phrase, your face. Build them from the Canva thumbnail template (see `CANVA_ASSETS_GUIDE.md`).
- **Titles:** lead with the searchable/curiosity phrase; keep under ~60 chars where possible.
