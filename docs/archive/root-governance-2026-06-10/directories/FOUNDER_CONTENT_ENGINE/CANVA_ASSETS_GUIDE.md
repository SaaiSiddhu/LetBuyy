# Canva Assets Guide — LetBuyy Founder Content

**Purpose:** make every post on-brand in 2 minutes by duplicating one of 5 reusable templates and swapping the text. No designing from scratch, ever.
**Source of truth:** the LetBuyy design system tokens (below). All visuals use these — your content should feel like it came from the same place as the product.

---

## 1. Brand System (from the real LetBuyy design tokens)

### Colors
| Role | Hex | Use |
|---|---|---|
| **Primary (brand violet)** | `#8B5CF6` | backgrounds, accents, the "LetBuyy" feel |
| **Primary CTA (deep violet)** | `#6D28D9` | buttons, key words, emphasis |
| **Deep / focus** | `#5B21B6` | darkest violet, gradients, depth |
| **Ink (text)** | `#111827` | primary text on light |
| **Subdued** | `#6B7280` | secondary text, captions |
| **Page** | `#F6F7F9` | light backgrounds |
| **Surface** | `#FFFFFF` | cards |
| **Success** | `#22C55E` | wins, "done", positive data |
| **Warning** | `#F59E0B` | caution, fee/leak callouts |
| **Critical** | `#EF4444` | "what went wrong", errors (sparingly) |
| **Info** | `#3B82F6` | neutral info |

**Two core schemes:**
- **Violet-on-light** (default): `#F6F7F9`/`#FFFFFF` bg, `#111827` text, `#8B5CF6`/`#6D28D9` accents. Clean, credible — great for LinkedIn + carousels.
- **Light-on-violet** (statement): `#6D28D9`→`#5B21B6` gradient bg, `#FFFFFF` text, `#8B5CF6` glow. Bold — great for hooks, reel covers, thumbnails.

### Typography
- **Body / display:** Inter or Plus Jakarta Sans (closest free Canva match to `--font-letbuyy-sans`). Headings 700–800, body 400–500.
- **Mono (code/architecture):** IBM Plex Mono or Space Mono — only on "Inside LetBuyy" architecture pieces.
- **Hierarchy:** one big idea per asset. Hook = 48–96px. Body = 24–32px. Label = 14–18px uppercase, letter-spaced.

### Shape & spacing
- **Corner radius:** 8–16px (matches product: `--lb-radius-md/lg/xl`). Pills/avatars = full round.
- **Padding:** generous — min 64px margins on 1080px canvases. Let it breathe.
- **Grid:** 8px spacing system (4/8/12/16/24/32/48/64).

### Logo / signature
- A consistent **"🟣 LetBuyy"** or violet dot + wordmark lockup bottom-left.
- Your handle **@saaisiddharth** bottom-right on every asset (so reshared posts trace back to you).

## 2. Design Principles
1. **One idea per asset.** If you need two ideas, make two assets.
2. **Hook is the design.** The first line should be readable as a thumbnail at 10% size.
3. **Brand violet is the constant.** Even minimalist posts carry one violet element.
4. **Honesty in visuals too.** Never mock a fake dashboard with fake numbers. Label concepts "concept."
5. **Light + dark friendly.** Test every template legible in both feed modes (avoid pure `#FFFFFF` text on `#8B5CF6` without enough weight; use `#FFFFFF` on `#6D28D9`+).

## 4. The 5 Reusable Templates

Each = one Canva design you **duplicate → edit text → post**. Built at 1080×1080 (square works on IG + LinkedIn + X); resize to 1080×1920 for reel/story covers and 1280×720 for thumbnails using Canva's resize.

### ⬛ Template 1 — Founder Update ("Day X Building LetBuyy")
- **Use for:** daily/weekly build updates, status posts, micro-wins.
- **Scheme:** Violet-on-light.
- **Layout:** Top-left label pill `DAY ___` (violet `#8B5CF6`, white text). Big headline area (the update, 1–2 lines, Ink). A short body line (Subdued). Bottom strip: 🟣 LetBuyy lockup + @handle. Optional small violet progress dots top-right.
- **What changes per post:** the day number + the one-line update + body line.
- **Variants:** "data variant" (add a simple bar/number block in Success/Warning for honest metrics like hours/commits).

### ⬛ Template 2 — Startup Lesson ("What I Learned Today")
- **Use for:** lessons, reflections, honest one-liners.
- **Scheme:** Light-on-violet (statement) — gradient `#6D28D9`→`#5B21B6`.
- **Layout:** Small top label `LESSON` (uppercase, letter-spaced, `#8B5CF6` glow). Centered big quote (white, 64–80px, max ~12 words). Attribution line `— Saai · building LetBuyy`. Bottom: handle.
- **What changes per post:** the lesson sentence.
- **Rule:** if it doesn't fit in ~12 words, it's not sharp enough yet.

### ⬛ Template 3 — Architecture Breakdown ("Inside LetBuyy")
- **Use for:** build-in-public, system thinking, the credibility flex.
- **Scheme:** Violet-on-light with **mono** accents.
- **Layout:** Top label `INSIDE LETBUYY` (mono, violet). Title (the concept). A simple diagram zone (boxes + arrows, violet outlines, 12px radius) — or a numbered list (1–4 leaks/steps). Bottom: 🟣 + handle + "concept" tag if showing UI.
- **What changes per post:** title + the diagram/list contents.
- **Variants:** "quote variant" (big merchant/insight quote), "iceberg variant" (10%/90%).

### ⬛ Template 4 — Founder Journey ("College → Startup")
- **Use for:** origin/identity series, life journey, personal story.
- **Scheme:** Violet-on-light, warmer — room for a **photo** (you).
- **Layout:** Left column: big arrow motif `COLLEGE → STARTUP` or the post's phrase (Ink + violet keyword). Right column: your photo in a 16px-radius frame. Bottom: handle. Photo-led, human.
- **What changes per post:** the phrase + the photo.
- **Variants:** "split-day" (left text / right photo grid of the day).

### ⬛ Template 5 — Weekly Review ("This Week at LetBuyy")
- **Use for:** Sunday reviews, monthly reviews, carousels' last slide.
- **Scheme:** Violet-on-light, structured.
- **Layout:** Header `THIS WEEK AT LETBUYY` + week/month number. Three labeled blocks: **WINS** (Success dot), **HARD** (Warning dot), **LEARNED** (violet dot), each with 1–3 short lines. Footer: "Next: ___" + handle.
- **What changes per post:** the three blocks + next focus.
- **Variants:** "Month review" (swap to `MONTH 1/2/3`, add a "what's next" band).

## 5. The 2-Minute Workflow
1. Open the matching template in your **LetBuyy Content** Canva folder.
2. **Duplicate** it (never edit the master).
3. Swap the text (and photo, for T4).
4. Check: one idea? hook readable small? violet present? honest?
5. Resize if needed (square → reel/story/thumbnail).
6. Export PNG → post → reply to comments.

> "Humans waste afternoons moving text boxes 3 pixels." These templates exist so you never do that again. Duplicate, type, post.
