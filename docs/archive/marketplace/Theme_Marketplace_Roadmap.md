## 1. Marketplace Overview

**URL:** themes.letbuyy.store
**Status:** ❌ 15% — Basic structure only

## 2. Theme Marketplace Features

- Browse themes by category (E-Commerce, Portfolio, Resume, Blog, Landing)
- Preview themes with store's actual data
- Free and premium themes
- Theme search and filtering
- Theme ratings and reviews
- Installation count tracking

## 3. Revenue Model

- **Revenue split:** 70% developer / 30% platform
- **Premium themes:** One-time purchase or subscription-based
- **Free themes:** Available to all plans

## 4. Developer Submission Flow (Planned)

```
1. Developer creates theme following template specification
2. Submit theme for review at themes.letbuyy.store/submit
3. Platform team reviews theme for quality, performance, security
4. Approved themes published to marketplace
5. Developer receives 70% of each sale
6. Dashboard for developers to track sales and analytics
```

## 5. Theme Pricing Guidelines for Developers

| Tier | Price Range | Features Expected |
|------|------------|-------------------|
| Free | $0 | Basic layout, 1 site type, minimal customization |
| Standard | $19-$39 | Multiple site types, full customization, responsive |
| Premium | $49-$79 | Advanced animations, unique design, priority support |
| Exclusive | $99-$149 | White-label quality, dedicated support, custom assets |

```
Rules:
  - Minimum price: $0 (free) or $19 (paid)
  - Maximum price: $149
  - Annual licensing only (one-time purchase, lifetime updates for major version)
  - Free trial: optional, max 14 days
  - Refund policy: 14-day money-back guarantee (enforced by platform)
```

## 6. Theme Quality Review Checklist

- [ ] Responsive design (320px, 768px, 1024px, 1440px tested)
- [ ] Dark mode fully supported
- [ ] Lighthouse Performance ≥ 90
- [ ] Lighthouse Accessibility ≥ 90
- [ ] No hardcoded colors (design tokens only)
- [ ] All sections handle empty states
- [ ] Images use next/image with lazy loading
- [ ] Fonts use font-display: swap
- [ ] Custom CSS variables documented
- [ ] All interactive elements have hover/focus/active states
- [ ] Respects prefers-reduced-motion
- [ ] Screenshots match actual appearance
- [ ] README includes documentation
- [ ] No external API calls or tracking scripts
- [ ] No deprecated APIs used

## 7. Marketplace Search Algorithm

```
Search ranking factors (weighted):
  1. Relevance (keyword match in name + description): 40%
  2. Popularity (install count, normalized): 25%
  3. Rating (avg stars, minimum 5 reviews): 20%
  4. Recency (newer themes boosted for 30 days): 10%
  5. Quality score (review checklist score): 5%

Filters available:
  - Site type (store, portfolio, resume, blog, landing)
  - Price range (free, $1-$29, $30-$59, $60+)
  - Rating (4+, 3+)
  - Category (minimal, bold, creative, professional, modern)
  - Sort: Popular | Newest | Rating | Price Low→High | Price High→Low
```

## 8. Recommendation Engine

```
Algorithms:
  1. SIMILAR THEMES: Content-based filtering
     → Same site type + similar design tokens (color temperature, layout type)
  2. POPULAR IN CATEGORY: Collaborative filtering
     → "Stores like yours also use..."
  3. TRENDING: Time-decay weighted installs
     → Installs in last 7 days, weighted more than older installs
  4. PERSONALIZED: Based on store type + industry
     → Recommended during onboarding survey results

Placement:
  - Theme marketplace homepage: "Popular", "New", "Trending"
  - Theme detail page: "Similar Themes", "By Same Developer"
  - Admin dashboard: "Recommended for Your Store" widget
```

## 9. Developer Payout Mechanism

```
Revenue Split: 70% developer / 30% platform

Payout Schedule:
  - Monthly, NET 30 after end of month
  - Minimum payout threshold: $50 (₹4,000)
  - Hold period: 14 days (for refund window)

Payment Methods:
  - Bank transfer (SWIFT/IFSC)
  - PayPal
  - Stripe Connect

Dashboard:
  developers.letbuyy.store/earnings
  → Real-time: installs, revenue, refunds
  → Monthly breakdown
  → Tax documents (TDS certificate / 1099)
```

## 10. Theme Bundles/Collections

```
Store owner can purchase:
  - Individual themes ($19-$149 each)
  - Theme bundle: 3 themes for price of 2 (developer opt-in)
  - "All Access" pass: all themes from one developer ($199/year)

Curated collections (platform-managed):
  - "Best for E-Commerce" — top-rated store themes
  - "Portfolio Picks" — curated creative themes
  - "Starter Pack" — best free themes for new users
  - "Dark Mode Collection" — themes with excellent dark mode
```
