# Global Operations Governance

Global operations are governed by region affinity, Cloudflare edge routing, regional queue ownership, replay routing, cache routing, telemetry routing, and disaster recovery evidence.

Rules:

- Multi-region certification must validate primary, failover, and edge topology.
- Regional routing overrides require operations API authorization and audit evidence.
- Cross-region replay and queue ownership must preserve tenant isolation.
- Regional disaster recovery must record failover and recovery evidence.
- Global readiness requires deployment, observability, security, SRE, failover, chaos, load, and event-store evidence.
