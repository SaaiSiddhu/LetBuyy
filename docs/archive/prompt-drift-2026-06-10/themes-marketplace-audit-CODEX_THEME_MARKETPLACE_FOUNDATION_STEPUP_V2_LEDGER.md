Generated by the 2026-06-08 local V2 closeout run. This ledger supersedes the prior step-up and closeout ledgers for the proof recorded here.

## Architecture Decisions

- D-1 one-time INR purchase remains the live commerce path; subscriptions stay marketing-only.
- D-2 developer revenue share uses a 15% dev default; final percentage and payout contract are human/prod cutover items.
- D-3 sample catalog is functional local/staging seed data with honest counts; production creative and third-party supply are cutover/onboarding items.
- D-4 legal pages render working draft policy structure; final binding wording is a cutover item.
- D-5 paid theme checkout uses `PAYMENTS_PROVIDER=mock` by default and Razorpay only when explicitly configured.
- D-6 migrations/seeds were applied to a local Supabase-compatible Postgres container; live DB apply remains a prod cutover.
- D-7 platform domain defaults remain env/governance-driven; `.com` DNS/allow-list cutover is outside this local run.
- D-8 checkout/download/developer surfaces use existing theme and UI contracts; no root config or scripts were edited.
- D-9 generated intelligence was not regenerated because topology was not changed by this closeout patch.
- D-10 coupon UI was removed from checkout; no dead coupon control remains.
- D-11 seeded perf/a11y metadata is marked as measurement-required, not fabricated numeric proof.
- D-12 sample reviews/install/download data are real rows or hidden at zero; no fabricated UI metrics were added.
