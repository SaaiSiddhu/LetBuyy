## 1. API Design Standards

- **Base URL:** `api.letbuyy.store`
- **Framework:** Hono 4.7 on Cloudflare Workers
- **Versioning:** `/api/v1/` prefix (NOT YET FULLY IMPLEMENTED)
- **Auth:** JWT Bearer token or session cookie
- **Validation:** Zod schemas on all inputs
- **Pagination:** `?page=1&limit=20` on list endpoints

### Response Formats
```json
// Success
{ "data": {...}, "meta": { "page": 1, "limit": 20, "total": 100 } }

// Error
{ "error": { "code": "VALIDATION_ERROR", "message": "...", "details": [...] } }
```

## 6. Middleware Chain

```
Request → CORS → Rate Limiter → Bot Protection (Turnstile) → JWT Validation
  → CSRF Check → Permission Check → Trial/Plan Check → Route Handler → Response

Middleware details:
  CORS: Origin whitelist (*.letbuyy.store), credentials allowed
  Rate Limiter: Upstash Redis, sliding window per IP + endpoint
  Bot Protection: Cloudflare Turnstile verification on auth routes
  JWT Validation: jose library, verify signature + expiry
  CSRF: Double-submit cookie pattern (planned)
  Permissions: Role-based check per route
  Trial/Plan: Verify store has active trial or subscription
```

## 7. Response Format Standards

```typescript
// Success (single resource)
{ "data": { id: "uuid", ...fields }, "meta": {} }

// Success (list)
{ "data": [...items], "meta": { "page": 1, "limit": 20, "total": 245, "totalPages": 13 } }

// Error
{ "error": { "code": "ERROR_CODE", "message": "Human-readable", "details": [...], "requestId": "req_xxx" } }

// Empty success (delete, update)
{ "data": null, "message": "Resource deleted successfully" }
```

## 8. Known API Gaps

- Not all endpoints have `/api/v1/` prefix
- Error codes not standardized across all routes
- Idempotency keys not implemented for mutations
- Request/response schemas not documented per endpoint
- Webhook event payloads not specified
- Missing pagination on some list endpoints
- No OpenAPI/Swagger spec generated
