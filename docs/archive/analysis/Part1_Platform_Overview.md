## 1. What Is LetBuyy

LetBuyy is a multi-tenant SaaS platform enabling users to build and manage e-commerce stores, professional portfolios, resumes, blogs, and landing pages — all from a single account. Think Shopify + WordPress + About.me combined.

## 2. Business Model

**Freemium SaaS:** Free tier → Starter ($9/mo) → Business ($29/mo) → Enterprise ($79/mo).
Additional revenue from theme/app marketplace commissions.
**Target Market:** India-first, then global. Small/medium merchants, freelancers, job seekers, content creators, marketers.

## 4. Domain Architecture

```
letbuyy.store               → Marketing + signup CTA
accounts.letbuyy.store      → ALL authentication
admin.letbuyy.store/{store} → Per-store CMS
*.letbuyy.store             → Published storefronts
apps.letbuyy.store          → Extension marketplace
themes.letbuyy.store        → Theme marketplace
console.letbuyy.store       → Super Admin
team.letbuyy.store          → Employee Portal
api.letbuyy.store           → REST API (Cloudflare Worker)
```

## 9. Key Differentiators

```
1. MULTI-SITE ARCHITECTURE: One account → multiple site types (store, portfolio, resume, blog, landing)
   → No other platform offers all 5 from a single dashboard

2. INDIA-FIRST PAYMENTS: Razorpay native, INR-first pricing, GST-ready
   → Shopify/Squarespace require complicated India setup

3. AI-POWERED CONTENT: Product descriptions, SEO, blog posts, portfolio text
   → AI credits included in every plan (even free tier)

4. ADAPTIVE ADMIN: Dashboard dynamically adapts based on site_type
   → Not a one-size-fits-all CMS — each type gets tailored tools

5. UNIFIED THEME SYSTEM: Themes work across site types with type-specific sections
   → One marketplace for all site types with compatibility matrix

6. DEVELOPER ECOSYSTEM: Theme + App marketplace with revenue sharing
   → 70/30 (themes) and 80/20 (apps) developer-friendly splits
```
