### Landing (90%)
Marketing site with homepage, pricing page, signup CTAs. NO auth pages — all redirect to accounts.

### Accounts (85%)
All authentication: login, signup, OTP verification, password reset, OAuth, onboarding. Rate limiting via Upstash Redis. Missing: refresh token rotation, 2FA.

### Admin (70%)
Per-store CMS dashboard at `admin.letbuyy.store/{store}`. Adaptive sidebar per site type. StoreProvider context. Missing: shipping config, full inventory, customer management.

### Storefront (50%)
Public storefronts via wildcard DNS. ISR with 60-second revalidation. Missing: cart persistence, checkout completions, search, customer accounts.

## 7. Key Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Framework | Next.js 16 | App Router, RSC, ISR for storefronts |
| API Runtime | Cloudflare Workers | Edge computing, global latency, cost |
| Database | Supabase PostgreSQL | Auth + DB + Storage + RLS in one platform |
| Auth | Supabase Auth + jose JWT | Built-in auth + custom JWT for flexibility |
| Caching | Upstash Redis | Serverless Redis, rate limiting built-in |
| Email | Resend | React Email templates, developer-friendly API |
| Mobile | Flutter | Single codebase for iOS + Android + macOS |
| Monorepo | Turborepo | Shared packages, parallel builds, caching |
| CSS | Tailwind CSS 4 | Design tokens, utility-first, dark mode |
| Rich Text | Tiptap | Extensible, collaborative-ready, JSON output |

### API Worker (50%)
Hono REST API on Cloudflare Workers. Store/product/order CRUD, blog API, portfolio API. Missing: versioning prefix, error standardization, webhook verification.

### Database (80%)
28 migrations, RLS enabled, seed data. Supabase-managed auth. Missing: soft deletes, audit columns, version columns, order_items relational table.
