## 1. Business Overview
A multi-tenant India-first commerce platform. Core unit = a merchant store (site_id). Merchants sell products; customers buy them; money flows through a canonical double-entry ledger.

## 2. Architecture Overview
414 tables, 156 RPCs, 22 domains, 4 Cloudflare Workers, 5 Vercel apps — all proxying the api-gateway (/v1).

## 3. Commerce Flow
Customer adds product → Cart → Checkout (totals + tax + shipping server-side) → Payment authorized/captured → Order created (create_checkout_order) → Inventory reserved → Shipping/fulfillment created → Notifications sent → Analytics updated

## 4. Payments Flow
Checkout submits → Server computes authoritative totals → Razorpay order created / COD selected → Razorpay signature verified (HMAC-SHA256) → confirm_order_payment_with_ledger (SECURITY DEFINER) → Double-entry ledger posted → Payout/settlement accrues

## 5. Merchant Flow
Merchant onboarding + KYC → Store creation → Product management → Inventory → Orders → Shipping → Analytics → Themes → Payouts

## 6. Customer Flow
Landing → Browse → Product → Cart → Checkout → Payment → Order → Tracking → Refund → Support

## 7. Security Model
Two issuers never crossed (customer HS256, merchant ES256). Forced RLS + verifySiteOwnership isolate tenants. Money mutations only via SECURITY DEFINER RPCs. Step-up HMAC gates refunds/payouts.

## 8. Infrastructure Model
Cloudflare Workers + Queues (incl dead-letter) + R2 + Hyperdrive → Supabase Postgres. 19 production secrets. Single deploy pipeline with a migrate gate + rollback.

## 9. Readiness Overview
