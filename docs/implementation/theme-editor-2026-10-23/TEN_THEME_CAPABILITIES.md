## Common generated contracts, not behavioral acceptance

- All ten generated artifacts use Liquid, contain **23 template keys**, **45 section
  definitions** and **one reusable block definition**. These are definition counts,
  not 45 active sections on every page, nor a promise all are legally insertable.
- All include distinct `page`, `blog` and `article` keys. Public routes already
  distinguish content pages, `/blog` listing and `/blog/:slug` article detail. These
  template files alone do not prove resource preview, assignment or pagination.
- The generated global schema groups are colors, typography, appearance and SEO.
  Field types are color/text/number/textarea/url. The exact source report shows no
  type-changing global normalization for these current artifacts.
- Section/block fields additionally use toggle/richtext/image/select/range; Threadline
  also declares product/collection references. Each field's metadata, legal parent
  declaration and default composition is in the machine report. Rendering consumption
  and service validation still need end-to-end qualification per exposed control.
- Only Threadline's builder applies the distinct niche implementation. The other
  nine retain their existing settings-overlay path. Their new working names and
  mockups must never be presented as installed completed niche packages.
- Editor structural operations, scoped media/resource references, style/apply modes,
  private preview, saved drafts, immutable releases, buyer navigation and niche data
  all require their own acceptance rows. No all-ten pass is claimed.

## Acceptance accounting

The first vertical slice must prove section and exact block identity; typed edit;
visible preview effect; save/reload; explicit local publication; frozen public
readback; private/newer-draft separation; failure/recovery; and page/blog/article
navigation. Repeat the applicable journey per installed version after its accepted
artifact becomes available. Existing Core contract tests can qualify shared safety
without certifying an unavailable new niche design.

Deletion validation is N/A at this point: nothing is deleted. No renderer default
has been changed. Third-party app execution stays DEFERRED_BY_GOVERNANCE under
ART-16/22/23 and NEVER-R3.
