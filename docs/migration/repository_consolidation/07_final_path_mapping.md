# 07 — The Canonical Path Mapping Ledger

**This document moves, renames, and deletes nothing.** It is evidence for the owner's signature on `00b_topology_amendment_draft.md`. Phase 3 (the actual renames) is blocked until that signature exists. Nothing in this ledger should be read as a decision already made — column "classification" and "action" are proposals for the owner to approve, adjust, or reject.

**Method.** Every row was checked against source, not inferred from folder names — application identity (`applicationId`/bundle ID), real consumer files, commit recency, and file counts were re-confirmed in Phases 0–1 and re-verified here where state could have changed (Phase 1 deleted ~31 GB of generated artifacts; nothing else changed). Where Phase 0's `04_application_survivor_scorecard.md` already marked something UNKNOWN, that UNKNOWN is preserved here, not silently resolved — new evidence discovered in this pass is cited explicitly.
